# 学生成绩管理系统
信息系统实践课程项目

## 项目简介
本项目是基于 Spring Boot + MySQL 的轻量化学生成绩管理系统，支持管理员、教师、学生三类角色，实现登录验证、学生/课程/成绩信息管理、课表管理、多条件成绩查询等核心功能，满足教学管理数字化需求。

## 核心技术栈
- 后端：Spring Boot 3.x、Spring Web、MyBatis、JWT（权限鉴权）
- 前端：HTML5、CSS3、JavaScript、Vue.js、Bootstrap
- 数据库：MySQL 8.0
- 开发/协作工具：IntelliJ IDEA、VS Code、Git + GitHub、Postman

## 快速运行指南
### 环境要求
- 后端：JDK 17、Maven 3.8+
- 前端：Node.js 14+
- 数据库：MySQL 8.0

### 部署步骤
1. **数据库初始化**：新建数据库 `db_student_score`（字符集 utf8mb4），导入 `sql/` 目录下的建表脚本；
2. **后端启动**：IDEA 打开 `backend/`，修改 `application.yml` 数据库账号密码，运行后端服务；
3. **前端启动**：VS Code 打开 `frontend/`，执行 `npm i` 安装依赖，再执行 `npm run dev` 启动前端；
4. **访问系统**：浏览器打开 `http://localhost:9122`。
