# 用户手册
## 1. 运行环境
- 后端：JDK 1.8 + Maven 3.6+
- 前端：Node.js 14
- 数据库：MySQL 8.0
- 工具：IDEA、VS Code、Navicat

## 2. 部署步骤
1. 创建数据库 db_student_score，字符集 utf8mb4
2. 导入 SQL 初始化脚本
3. 配置 application.yml 数据库账号密码
4. 启动后端服务
5. 前端执行 npm i 与 npm run dev
6. 访问 http://localhost:9122

## 4. 功能使用说明
### 4.1 管理员
- 用户管理、课程管理、成绩管理、课表管理、数据统计

### 4.2 教师
- 个人课表、成绩录入、成绩查询、成绩统计

### 4.3 学生
- 个人成绩查询、个人课表查询

## 5. 注意事项
- 成绩必须在 0–100 之间
- 未登录无法访问功能页面
- 不同角色权限不可越权
