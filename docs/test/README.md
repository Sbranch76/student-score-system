\# 学生成绩管理系统-测试文件夹说明

\## 文件说明

1\. `init\_db.sql`：测试环境数据库表结构初始化脚本，清空原有表并重建结构

2\. `insert\_test\_data.sql`：核心测试数据插入脚本，包含管理员、专业、课程、学生等基础数据

3\. `query\_test.sql`：数据验证查询脚本，用于确认数据插入是否成功



\## 使用步骤

1\. 先执行 `init\_db.sql` 初始化表结构

2\. 执行 `insert\_test\_data.sql` 插入测试数据

3\. 执行 `query\_test.sql` 验证数据是否正确插入



\## 注意事项

\- 执行脚本前确保已创建 `db\_student\_score` 数据库

\- 测试环境建议使用独立的数据库实例，避免影响生产数据

\- 密码字段为明文（123456），生产环境需替换为加密后的密码
