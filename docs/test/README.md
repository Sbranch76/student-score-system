# 测试文件夹说明
本目录存放学生成绩管理系统的**完整测试材料**，包含数据库脚本、测试计划、测试用例、测试执行结果、缺陷记录及修复验证，形成测试全流程闭环。

所有测试过程均已提交 Git 仓库，实现测试过程可追溯、可验证。

---

## 一、数据库脚本（用于环境初始化）
1.  **init_db.sql**：数据库表结构初始化脚本，创建系统所需全部数据表
2.  **insert_test_data.sql**：测试数据插入脚本，包含管理员、学生、课程、成绩初始化数据
3.  **query_test.sql**：数据验证查询脚本，用于校验数据插入是否正确
4.  **run_test.bat / run_test.sh**：一键执行脚本，自动完成初始化→插入→验证全流程

---

## 二、测试文档（测试全流程记录）
1.  **测试计划.md**
    测试目标、测试范围、测试环境、人员分工

2.  **测试用例表.md**

## 三、接口测试说明
使用 Postman 完成接口测试：
- 登录接口：获取 Token
- 学生列表接口：鉴权通过，返回正常数据
- 测试截图存放于 assets/ 目录，报告中可直接查看

---

## 四、使用步骤
1.  确保 MySQL 服务已启动，创建 db_student_score 数据库
2.  执行 run_test.bat（Windows）或 run_test.sh（Linux/Mac）
3.  输入数据库密码，自动完成初始化与数据插入
4.  查看测试结果与验证记录
