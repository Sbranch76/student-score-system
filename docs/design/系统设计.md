# 系统设计文档
---
## 一、系统架构
采用 B/S 架构 + 前后端分离模式
浏览器 → 前端页面 → Spring Boot 后端 → MySQL 数据库

## 二、功能模块设计
### 1、需求概述
1. 课程信息管理：课程新增、修改、删除、条件分页查询。
2. 课程表管理：排课设置、课程表录入与修改。
3. 用户信息管理：管理员、学生、教师信息的新增、修改、删除、查询。
4. 成绩信息管理：成绩录入、修改、查询、统计分析。
5. 用户登录：三角色登录、身份验证、密码修改。
6. 权限控制：不同角色访问不同功能页面，越权访问自动拦截。

### 2、软件结构
系统分为四大核心模块：课程管理、课程表管理、成绩管理、用户管理。

- 课程管理：负责课程信息维护与查询。
- 课程表管理：负责排课、课表展示与维护。
- 成绩管理：负责成绩录入、修改、查询、统计。
- 用户管理：负责管理员、学生、教师信息维护。

## 四、模块处理逻辑

### 1、用户登录流程
1. 用户输入账号、密码、选择角色。
2. 后端校验账号密码是否正确。
3. 校验通过生成JWT令牌，返回角色与用户信息。
4. 前端根据角色跳转到对应首页。
5. 未登录或token无效则拦截访问。

### 2、查询课程信息流程
1. 用户输入查询条件。
2. 系统根据关键字匹配课程数据。
3. 返回分页结果展示。
4. 无输入则展示全部数据。

### 3、查询用户信息流程
1. 用户输入学号、姓名、专业等条件。
2. 系统按条件匹配学生、教师、管理员数据。
3. 返回对应列表数据。

### 4、课表录入流程
1. 管理员选择学年、学期。
2. 选择对应课程进行排课。
3. 未选择则置空。
4. 保存后生成课表数据。
