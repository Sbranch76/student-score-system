2. 数据库设计

4. 前端页面开发

### 3. 后端开发任务
#### 刘敏祺（后端核心开发）
- Spring Boot 项目架构整体搭建
- 统一返回封装、分页工具、通用工具类开发
- 登录接口、身份认证、JWT 令牌生成与校验
- 权限拦截器、路由拦截、接口鉴权开发
- 全局异常处理、跨域配置、过滤器配置
- 课表管理模块（增删改查、排课、周课表）
- 文件上传模块（头像/文件上传、存储、URL生成）
- 用户基础模块（学生/教师/管理员公共逻辑）

#### 朱宁静（后端业务开发）
- 学生信息管理模块（增删改查、条件查询）
- 课程信息管理模块（课程、课程详情）
- 成绩管理模块（成绩录入、修改、查询、统计）
- 专业信息管理模块（专业增删改查、数据关联）
- 教师-课程关联模块、学生-课程关联模块
- 分页查询、条件筛选、多表关联查询开发
- 所有业务模块的 Mapper/Service/Controller 实现
- 接口注释完善、DTO 实体封装、数据校验

- Axios 接口封装、前后端联调：崔慧敏
- 表单校验、非空校验、分数范围校验：崔慧敏
- 页面交互、样式优化、浏览器兼容：崔慧敏
